# website-assets

Image assets for the UCF Data-Enabled Photovoltaics group website (https://ucf-dpv.notion.site).

- `headshots/` — team member photos
- `publications/` — one representative figure per publication, named by CV index (J44.jpg, C60.png, …)
- `projects/` — figures used on Research Projects pages, named by award number

Files are referenced by their raw URLs, e.g.
`https://raw.githubusercontent.com/ucf-photovoltaics/website-assets/main/publications/J44.jpg`
